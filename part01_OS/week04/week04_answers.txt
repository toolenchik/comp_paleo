Answers:
1. IFS=$'\t' tells read that fields are separated by tabs. The first field goes into CATALOG_NUM, and the remaining fields go into REST.
-r keeps backslashes unchanged.IFS means input field separator, which is set to tab deliminated here, because the file is tab deliminated.
2. [[ "$CATALOG_NUM" != "$PREFIX"* ]] checks whether the catalog number does not start with the prefix. [[ ]] supports pattern matching (*) safely.
3. tee -a "$LOG_FILE" prints the message on screen and appends it to the log. Simple redirection writes only to the file.
4. Bash normally runs the loop in a subshell --> Changes to BAD_COUNT disappear when the loop ends.
lastpipe bash and the process substitution pattern run the script in the current shell, so BAD_COUNT remains available afterward.
